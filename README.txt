SKY DUEL - SPACE BUILDER / EXPLORER
==================================

この試作版では、空戦ゲームを宇宙船の探索・採掘・建造・戦闘へ発展させています。

起動方法
--------
Three.jsをCDNから読み込むため、インターネット接続が必要です。
HTMLファイルを直接開いて動かない場合は、フォルダ内でローカルWebサーバーを起動してください。

Pythonがある場合：
  python -m http.server 8000

その後、ブラウザで次を開きます：
  http://localhost:8000/

PC操作
------
W / A / S / D または矢印キー : 前後左右移動
Q / E                         : 高度を下げる / 上げる
マウスドラッグ                : 視点操作
左クリック / Space            : 射撃
F                             : 小惑星の採掘（近くで長押し）
Shift                         : ブースト
B または SHIP DESIGN          : 建造画面

スマホ操作
----------
左側をタップして動かす : その場所に移動スティックが出現
右下のFIREスティック   : 射撃
右側のその他の場所     : 視点操作
HOLD TO MINE           : 小惑星の近くで長押し
画面上のボタン         : ブースト・上昇・下降

採掘と建造
----------
小惑星の近くでFキー、またはHOLD TO MINEボタンを長押しすると資材を回収できます。
SHIP DESIGNを開くと9x9のグリッドで部品を配置・取り外しできます。

部品の効果：
  船体       : 防御力を少し上げる
  エンジン   : 移動速度を上げる
  武器       : 命中時の攻撃力を上げる
  発電機     : ブーストの回復を速める
  シールド   : 被ダメージを軽減する
  貯蔵庫     : 採掘で得られる金属を増やす

宇宙船の設計と資材数は、このブラウザのローカルストレージに保存されます。
この段階では1隻の自機、採掘可能な小惑星帯、CPU敵船1隻の基本システムです。
